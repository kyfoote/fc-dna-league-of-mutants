# FC DNA: League of Mutants

This project is now packaged as a runnable Phaser + TypeScript game using Vite.

## Requirements

- Node.js 20+
- npm 10+

## Quick start

1. Install dependencies:

   npm install

2. Run the game locally:

   npm run dev

3. Open the URL shown in the terminal (typically http://localhost:5173).

## Production build

- Build:

  npm run build

- Preview the production build:

  npm run preview

## Notes

- The runnable game entry is at src/runtime/main.ts.
- The current gameplay loop includes:
  - Title screen
  - Mutant draft picks
  - Match simulation
  - Result screen and replay flow
